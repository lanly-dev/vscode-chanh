The fastest path is the managed one: set
`chanh.serverMode` to `LEMOND`, then [Start Server](command:chanh.startServer)
downloads the `lemond` binary if needed and starts it on port 8000.
[Open Settings](command:chanh.openSettings)

Already running Lemonade yourself? Start your Lemonade installation, keep the
default `LEMONADE` mode, and Chanh connects to it on port 13305. Use
[Refresh Server](command:chanh.refreshServer) if you start it after Chanh.
